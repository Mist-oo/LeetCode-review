| 事项 | 最终选择 | 原因或约束 |
| --- | --- | --- |
| 产品重点 | 刷题记录与复习笔记 | 用户主要希望解决刷过就忘、缺少记录的问题 |

| 选题 | 按类型＋完全随机 | 随机模式减少相邻同类型题目的提示依赖 |

## 技术选择状态

尚未确定框架、应用开发语言及存储实现。Python 是刷题编辑器语言，不等同于后端语言要求。PyCharm 中的虚拟环境和 Git 仓库已建立，并不代表技术栈已经确定。

## 2026-10-29：第一版实现选择

- 后端：Python 3.11+ 标准库 ThreadingHTTPServer，监听 127.0.0.1，不暴露到局域网；前端为原生 HTML/CSS/JavaScript。
- 持久化：SQLite，个人数据与题面缓存均位于忽略的 data/；临时测试数据库与正式数据库隔离。
- 日期：固定 Asia/Shanghai，服务器校验当天写入；首页跨天后自动刷新日期，打开的练习不自动搬移草稿。
- 界面：矩阵主页与并排题面/代码的练习页；更早日期每次增加 14 天，不做统计。
- 编辑器：CodeMirror 5.65.21，本地 Python mode；Markdown 使用 Marked 15.0.12 与 DOMPurify 3.2.7，均保存原许可。
- Hot 100 元数据固定为 100 题与 17 分类；题面缓存来自 doocs/leetcode 的 description 区段，保留上游版本链接和许可。缺失题面允许用户粘贴补充，图示保留原站地址。
- Windows 提供 start.cmd，PyCharm 可直接运行 app.py；首次克隆缺少题面时尝试下载，失败仍可启动并手动补充。
