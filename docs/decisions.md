## 技术选择状态

尚未确定框架、应用开发语言及存储实现。Python 是刷题编辑器语言，不等同于后端语言要求。PyCharm 中的虚拟环境和 Git 仓库已建立，并不代表技术栈已经确定。

## 2026-10-29：第一版实现选择

- 后端：Python 3.11+ 标准库 ThreadingHTTPServer，监听 127.0.0.1，不暴露到局域网；前端为原生 HTML/CSS/JavaScript。
- 持久化：SQLite，个人数据与题面缓存均位于忽略的 data/；临时测试数据库与正式数据库隔离。
- 日期：固定 Asia/Shanghai，服务器校验当天写入；首页跨天后自动刷新日期，打开的练习不自动搬移草稿。
- 界面：矩阵主页与并排题面/代码的练习页；更早日期每次增加 14 天，不做统计。
- 编辑器：CodeMirror 5.65.21，本地 Python mode；Markdown 使用 Marked 15.0.12 与 DOMPurify 3.2.7，均保存原许可。
- Hot 100 元数据固定为 100 题与 17 分类；题面缓存来自 doocs/leetcode 的 description 区段，保留上游版本链接和许可。缺失题面允许用户粘贴补充，图示保留原站地址。
- Windows 提供 start.cmd，PyCharm 可直接运行 app.py；首次克隆缺少题面时尝试下载，失败仍可启动并手动补充。

## 2026-10-30：第二版实现选择

- 范围改为仅 Hot 100。旧自选数据保留但隐藏；所有记录/笔记仍按原有方式保存。
- 判题采用个人本机 Python 子进程，不引入 Docker；临时工作目录不是安全沙箱。每批限时 3 秒，16 MB 合并输出上限，256 MB 采样内存监控，Windows Job Object 清理整棵进程树。
- 程序按逐题固定的行协议连续读取到 EOF，不含 T。每个正式批次最多 16 组，压力数据单独运行；自定义运行最多 32 组、800 万字符，可容纳完整失败批次复现。
- 固定套件每题有 128 组种子随机与普通/边界/上界压力数据，版本含协议标记和内容哈希。随机加强使用 256 组随机，保存种子并支持同种子复测。
- 正式提交全量持久化，运行不进历史；失败数据按需揭示。每日复习结果仍手动，服务器按当天完全相同代码关联有效提交，防止旧 AC 错配新代码。
- 本地 Jedi 0.19.2 静态分析进程复用，提供变量、方法、模块和参数补全；前端 CodeMirror show-hint，同步支持自动提示、Ctrl+Space 与关闭开关。
- 移除自选题新增 API/界面，保留旧表行；迁移增加 submissions 与 records.submission_id，不删除旧记录、草稿、笔记。

### V3-01 实现决定

- 使用 CodeMirror 同版本官方 closebrackets，不另行替换编辑器。
- 官方源码保持原样；Python 特有的转义、三引号与字符串前缀兼容逻辑放在自有 editor-tools.js，便于审计与维护。
- 浏览器验收使用独立 8766 服务与数据库，脚本拒绝在正式 8765 运行。

### V3-02 实现决定

- 代码默认字体为 14px、字重 600，保留本机 Consolas 等宽字体回退，覆盖样式位于 editor.css。
- 字体改动限于 CodeMirror 区域，普通题面与页面文字不随之缩放；实际 Chrome 中已核验代码、行号及真实 Jedi 菜单布局。

### V3-03 实现决定

- 在编辑器 wrapper 上使用非被动捕获 wheel 监听，仅处理 ctrlKey 的缩放；普通滚动不拦截。字号范围 10～28px，使用浏览器本机偏好存储并校验数值。
- 浏览器真实 Ctrl＋滚轮和普通纵横滚动已经验证；真实触控板手势须另行确认，不能将合成事件通过记作硬件通过。
