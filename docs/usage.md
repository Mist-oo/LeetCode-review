# 使用说明

## 启动与停止

需要 Python 3.11 或更新版本，无需安装 pip 包。Windows 双击项目根目录 `start.cmd`，会优先使用项目 `.venv`，否则使用 PATH 中的 `python`，随后打开浏览器。

也可以在 PyCharm 打开根目录 `app.py` 后运行，点击控制台中的 `http://127.0.0.1:8765`。

命令行启动：

```powershell
.\.venv\Scripts\python.exe app.py
```

如果没有虚拟环境，可使用 `python app.py`。停止时在运行窗口按 Ctrl+C，或使用 PyCharm 停止按钮。关闭浏览器不会停止服务。

如端口已占用，先检查页面是否已打开；也可以用 `python app.py --port 8766` 改用其他端口。

## 第一次使用

1. 首页已经有 100 道题。勾选以前做过的题，点击“标记以前做过”，只加入随机题池，不会补造历史结果。
2. 左侧选择分类，再点击题名开始练习；也可以按题单、状态或题名筛选。
3. 点击“随机复习”，在当前筛选条件下的已做题中等概率抽取。可能连续抽到同一道题，不管理复习轮次。
4. 在右侧编写完整 Python 程序，草稿自动保存。复制到外部平台自行验证，再手动标记结果。
5. 独立完成且无错选 ✅；看提示或过程中出错选 ❌，可添加错误标签和说明，最后点击“保存今日记录”。

## 记录与笔记

- 首页连续显示今天及前 6 天，空白表示未练习；点击“更早日期”向右查看更早日期。
- 点击当天空格开始练习；悬停 ❌ 查看标签，点击已有结果查看代码和说明。当天可修改，历史只读。
- 每题每天只有一条结果，重复保存替换当天结果。草稿自动保存与正式结果独立，不会仅因打开/跳过题目就生成 ✅/❌。
- 当天草稿会恢复；新一天代码区从空白开始。跨日未保存的编辑会被服务器拒绝，请先复制保留，再返回首页重新打开题目。
- 在“解题笔记”中整理五个固定栏目，点击“保存笔记”。Markdown 和代码块可预览，参考代码单独填写。
- “练习历史”可查看、复制以前的代码；查看笔记或历史不会自动改变结果。
- 随机模式默认隐藏类型和历史；长期笔记需要主动切换标签查看。

## 题目内容

本机已缓存 Hot 100 的全部中文题面。日常文字阅读、编辑和记录不需要联网；部分题目图示引用原站地址，仍需要联网。

GitHub 不包含本机题面缓存。从 GitHub 重新克隆后，第一次双击 `start.cmd` 会尝试下载；也可以手动运行：

```powershell
python cache_statements.py
```

下载完成后重新启动应用。下载失败也可打开应用，通过“编辑 / 补充题面”粘贴原题。已有题面不会被缓存导入覆盖。来源与许可见根目录 `THIRD_PARTY.md`。

## 数据位置

- `data/review.db`：个人题库标记、练习记录、代码草稿、标签和长期笔记。
- `data/statements.json`：初次导入用的题面缓存。

这些文件只保存在本机，Git 会忽略整个 `data/`。GitHub 保存源代码和开发文档，不包含你的个人使用记录。

## 开发验证

```powershell
python -m unittest discover -s tests -v
```

测试使用临时数据库，不改动个人数据。前端 JavaScript 语法可用 `node --check static/app.js` 检查，Node.js 仅用于开发检查，运行应用不需要它。
