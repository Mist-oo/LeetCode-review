# 设计决策记录

日期：2026-10-29。记录最终选择及原因，后续变更在本文件追加。

| 事项 | 最终选择 | 原因或约束 |
| --- | --- | --- |
| 产品重点 | 刷题记录与复习笔记 | 用户主要希望解决刷过就忘、缺少记录的问题 |
| 记录维度 | 题目 × 实际日期 | 不单独管理复习轮次 |
| 结果标准 | 独立且无错为 ✅，提示或出错为 ❌ | 表达掌握情况，由用户手动判断 |
| 同日重复 | 每题每日一条 | 简化记录，不保存多次结果和次数 |
| 日期展示 | 最近 7 个自然日连续显示，最新在左 | 同时观察近期记录及空白日期 |
| 历史范围 | 更早日期向右滚动查看 | 保留长期记录的浏览入口 |
| 统计 | 第一版不做 | 用户最终取消通过率和周期统计 |
| 选题 | 按类型＋完全随机 | 随机模式减少相邻同类型题目的提示依赖 |
| 随机题池 | 已做题，可限定类型或题单 | 支持批量标记以前做过，不补造历史结果 |
| 练习环境 | 原题＋Python 文本编辑器 | 外部平台自行验证，第一版不实现运行和判题 |
| ACM 格式 | 用户自行编写，不附加格式说明 | 保留力扣原题示例 |
| 笔记结构 | 四个文字栏目＋Python 参考代码 | 便于按固定结构回顾，与每日错误独立 |
| 提示与结果 | 主动查看内容，不自动标记 ❌ | 最终结果完全由用户手动决定 |
| 草稿 | 当天恢复，新一天空白 | 保留未完成进度，避免旧代码提示答案 |
| 使用环境 | 电脑端本地网页，无账号 | 首版仅供个人单机使用 |
| 补录与备份 | 第一版均不提供 | 用户明确缩减范围 |
