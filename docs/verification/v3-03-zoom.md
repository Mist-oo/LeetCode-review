# V3-03：字号缩放与偏好验收

日期：2026-10-30。状态：实现完成，浏览器验收及用户真实触控板确认通过。

## 改动

- editor-tools.js 支持代码区 Ctrl＋wheel 缩放、10～28px 范围、A−/A＋、默认 14px 重置与本机偏好保存，处理无效偏好及不可用存储。
- 普通 wheel 保留 CodeMirror 的纵横滚动，字号调整不触发源码更改或影响题面/整页字号。
- 浏览器将触控板缩放表达为带 ctrlKey 的 wheel，依据见 [MDN wheel 事件说明](https://developer.mozilla.org/en-US/docs/Web/API/Element/wheel_event)。具体硬件/驱动行为需实测。

## 已验证

tests/browser/v3-zoom.js 在独立 8766 服务完成 14 项断言：默认、增大、减小、真实浏览器 Ctrl＋滚轮增大、页面缩放不变、偏好保存、普通纵向滚动、普通横向滚动、刷新恢复、最大/最小限制、源码不变、重置、无效偏好回退。

Ctrl＋滚轮由 Playwright 键盘修饰键及浏览器 wheel 输入驱动，普通纵横滚动核对实际 scrollTop/scrollLeft。上下界用合成 wheel 事件补充，未使用这些事件声称真实硬件验收。

## 真实设备反馈

2026-10-30，用户对本机正式页面反馈“两种操作都正常”：两指捏合/张开只调整代码字号，普通两指同向滑动仍滚动代码。本项硬件门槛由用户实际操作确认，不以浏览器合成事件替代。
