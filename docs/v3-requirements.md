# 第三版需求：编辑体验与题面变式复习

确认日期：2026-10-30。状态：需求已确认，开发中。按 [开发计划](v3-development-plan.md) 逐项实现、验证、记录、提交并推送；完成状态以该计划和逐功能验收文件为准。

本文件承接第二版，不改变 Hot 100、Python ACM 多组读取到 EOF、本机判题、手动每日结果及既有记录/草稿/笔记的规则。

## 1. 目标

- 补齐代码输入时的符号配对，改善字体可读性与触控板字号操作。
- 随机复习时通过不同叙述识别题目本质，降低原题标题、分类与原文带来的记忆提示。
- 同时支持随项目提供的固定改写，以及用户自行配置模型服务的 AI 改写。

## 2. 符号配对

- 输入 `(`、`[`、`{`、单引号或双引号时，在适合配对的上下文自动补齐另一半。
- 选中文字后输入左符号或引号，将选中内容包在符号内。
- 光标右侧已有对应闭合符号时，再输入该符号向右跳过，避免重复。
- 光标处于空配对中间时，退格删除整对。
- 采用常见 IDE 的上下文行为，保留 Python 字符串、转义、注释、多行字符串、缩进及现有补全的正常输入；不能简单地将每次引号按键都扩展为两个引号。
- 粘贴和恢复历史代码不得额外插入符号或改变源码；编辑后的草稿仍按既有规则保存。

## 3. 字体与缩放

- 默认代码字号调整为 14px，字重稍加粗；具体字体回退和字重在实现中以实际显示效果核验。
- 在代码区域，两指捏合缩小、张开放大字号；普通两指同向滑动仍滚动代码。
- 支持 Ctrl＋滚轮作为备用操作，提供一键恢复默认字号。
- 缩放只影响代码区域，不能把整个网页一起缩放；记住用户选择的字号。
- 实现时设定合理字号范围并记录，范围数值尚未单独约定。需要在本机浏览器和触控板上验收，合成 wheel 事件只能验证处理逻辑，不能替代真实硬件手势验收。

## 4. 随机复习的题面呈现

- 本轮变式题面用于随机复习；按类型或从矩阵打开的普通练习保持原有原题展示。
- 随机复习默认展示改写标题与描述，不直接出现原题名、题号、分类和力扣链接。
- 提供“查看原题”入口，主动点击后显示原始描述及原题信息和链接；进入下一题时重新隐藏。
- 改写与原题始终对应同一道题，使用同一判题协议与测试集，不另建复习记录或重复题目。
- 检查题面、顶部标题、浏览器标题、提示文案、ACM 区域及其他默认可见区域，避免无意泄露原题身份；隐藏呈现不代表必须从本地 API 中移除原题信息。
- 笔记、历史、草稿和每日手动结果继续沿用现有主动查看与保存规则；查看原题不会自动修改 ✅/❌。

## 5. 改写尺度与内容质量

- 采用面试场景改写：更换背景、对象名称、叙述顺序与示例，而不只是替换几个同义词。
- 保留原题的核心条件、数据约束、可接受解的范围及 ACM 输入输出协议，不增加原题没有的业务规则。
- 不提示算法、所属题型、解法或复杂度结论。
- 重新编写的示例必须合法，输入需通过现有约束检查，输出需与现有参考计算及多解校验一致。
- 固定改写逐题审核语义一致性；AI 输出也要做结构、必要条件、示例等可执行检查。自动检查不能证明自然语言语义完全等价，不能将 AI 文本标记为人工审核过。
- AI 改写失败或未通过检查时，说明原因并使用固定改写，不能把未经检查的输出当作有效题面。
- 原题展示继续保留现有来源与许可；新增内容的来源说明随实际实现补充。

## 6. 两种题面来源

### 固定改写

- Hot 100 每题准备 3 个固定版本，共 300 个版本，随项目保存并支持离线使用。
- 随机复习时轮换展示版本，避免同题连续只看到同一说法；具体轮换状态的存储在实现记录中说明。
- 100 题覆盖、每题版本数量、必要字段、示例与协议一致性必须有可审计的检查结果，不能仅用总数量代替逐题审核。

### AI 生成

- 用户自行配置模型服务的 API 地址、密钥和模型名，不要求电脑运行本地模型。
- 密钥只保存在本机，不写入 Git、文档、截图或普通日志；个人配置与 AI 缓存不上传 GitHub。
- 生成后按题目保存可复用版本，再次抽到同题时优先使用缓存。
- 提供“换个说法”按钮，由用户主动请求新版本；AI 服务可能产生费用。
- 具体 API 兼容协议、请求格式、超时、缓存版本和配置入口属于实现决定，落地时写入设计决策及使用说明，尚未承诺支持任意厂商的所有协议。
- 默认不把用户代码、笔记、错误记录等个人练习数据发送给模型。生成所需上下文限于题目、约束、协议与示例等必要信息。

### 默认与回退

- 首次使用默认选择固定改写，之后记住用户上次选择的来源。
- AI 模式优先复用已有缓存；缺少可用配置或生成失败时，明确提示并展示固定改写。
- 模式选择、加载状态、错误与回退结果应清楚可见，避免固定题面被误认为本次 AI 新生成。

## 7. 关键验收场景

1. 左括号/引号补全、选区包裹、闭合跳过、空配对退格，以及字符串/转义/粘贴/撤销与已有补全协同正常。
2. 初始 14px 且比当前更粗；缩放仅改变代码区，刷新仍保留，恢复默认有效；两指滑动仍能滚动长代码。
3. 随机题默认只出现改写内容；原题名/题号/分类/链接在点击前隐藏，下一题恢复隐藏；普通练习展示不变。
4. 固定数据覆盖 100/100 题，每题恰好 3 个可用版本，轮换与离线加载正常，所有示例检查通过。
5. AI 配置保存与调用可用，缓存优先、换个说法生成新版本；配置缺失、超时、网络/接口错误及无效输出均有明确提示与固定题面回退。
6. 同一题切换题面来源或展开原题不影响判题、每日记录、笔记及草稿；旧数据迁移保留。
7. 测试使用隔离数据库与测试配置，不修改正式个人记录；提交内容不包含密钥或个人缓存。
