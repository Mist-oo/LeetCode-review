# V3-09：AI 改写生成与结果检查

日期：2026-10-30。状态：生成服务及检查路径通过本地模拟协议验收；界面、缓存尚待后续，不声称已测任意真实厂商模型。

## 行为

- POST /api/problems/<id>/ai-variant 调用已配置兼容服务，先生成再题意复核；固定条件/约束/协议由应用控制，模型不得覆盖。
- 示例必须是两个按字段顺序的 JSON 参数数组，原输入范围、EOF 往返、参考/独立答案均检查；禁止过大的展示示例，避免枚举爆炸；学生判题规则不变。
- 拒绝明显题名/平台/算法提示、重复原文、遗漏条件编号、无效/截断/过大响应。语义复核发现遗漏/新增/矛盾则拒绝，模型复核不能形式证明等价。
- 同次生成固定服务配置快照，最多两次收费模型请求，不自动重试；错误响应不回传服务商正文/密钥，不跟随重定向。等待和响应大小有限制。

## 验证

- tests/test_ai_variants.py：13 项通过，-W error::ResourceWarning 无警告。真实本地 HTTP 模拟服务验证 URL、Bearer、model/messages/stream 请求、响应解码、两阶段调用和配置快照。
- 检查缺条件/非法样例/额外字段/算法提示/原题名/重复原文、语义否决、401/429/500/重定向、超时/超长/截断/错误 JSON、忙碌拒绝、最短窗口唯一性。
- 全部 100 题的结构化示例解码与独立计算路径均覆盖；测试叙述夹具不参与语义复核，因此该项不等于真实模型对 100 题的语言验收。
- tests/test_ai_settings.py 5 项及 tests/test_http.py 10 项回归通过；未配置时 API 返回明确失败，不请求外部服务。
- 本地测试仅使用虚构密钥。未读取/使用用户真实密钥，未调用外部付费模型；实际厂商兼容性与内容质量依用户配置服务表现，不将模拟结果记成真实调用成功。
