# 第二版使用说明

## 启动与升级

Windows 双击 `start.cmd`，检查并安装判题/补全依赖，然后打开浏览器。PyCharm 运行 `app.py` 前先执行 `python -m pip install -r requirements.txt`。地址为 http://127.0.0.1:8765 。按 Ctrl+C 或 PyCharm 停止按钮停止服务；关闭浏览器不会停止服务。

数据在 `data/review.db`，题面缓存为 `data/statements.json`，均不上传。第一版首次启动自动迁移，不删除记录、草稿、笔记或旧自选题；旧自选题仅隐藏。

从 GitHub 新克隆时，首次启动尝试下载题面，也可手动执行 `python cache_statements.py`，完成后重启。图示可能需联网，题面保留 doocs/leetcode 出处与 CC BY-SA 4.0 声明。

## 选题与 ACM 协议

首页勾选做过的题后“标记以前做过”，只加入随机题池，不生成历史结果。左侧选分类，点击题名练习；“下一题”按筛选顺序切换，随机复习从当前范围已做题中等概率抽取，可以重复。

第二版仅 Hot 100，不能添加或上传自选题单。

第三版开发中的随机复习默认显示场景标题与描述，隐藏原题身份，点击“查看原题”才展开题号、原题名、分类及链接；换题后重新隐藏。普通按题练习保持原样。当前固定改写覆盖 80/100 题，其余题明确提示尚未提供，可主动查看原题继续练习；内容覆盖进度见开发计划。

场景题面的两组样例会同步到 ACM 页和默认测试输入，已有自定义测试输入不会因异步加载被覆盖；显示层变化不修改每日手动结果。固定版本按题目轮换，浏览器记住上次版本，亦可主动“换个场景”。AI 来源和来源选择仍在后续开发。

练习先查看 **ACM 格式**：每题规定字段、长度、组边界、输出和连续两组公开样例。

- 没有 T，读取到 EOF；`sys.stdin.read()` 或 `input()` 循环均可，按题目协议解析。
- 空数组和空字符串也可能占用空行，不能把所有空行当结束或跳过。
- 链表的环/交点以节点下标说明；树使用队列层序和 null。
- 多解允许不同合法顺序或答案，但不能遗漏、重复；具体见输出说明。
- 不提供输入输出模板，默认空白，自行编写完整程序。

## 运行与提交

**运行输入**：展开测试输入，默认公开样例，可改为自定义数据，最多 32 组、800 万字符。查看实际/预期输出与异常，不进入提交历史，也不生成矩阵记录。完整失败批次最多 16 组，压力批次为单组，可直接复现。

**提交判题**：完整固定套件，显示排队/判题状态、已检查和通过组数，支持取消。本机只同时执行一个任务，避免拖慢电脑。

默认隐藏正式测试数据。失败后可“揭示首个失败用例”，查看本组输入、预期和解析结果。“将完整失败批次放入测试输入”会连同此前各组复制，便于复现状态未重置问题；多解预期仅展示一种合法形式。

**随机加强**：增加随机组，保留种子与版本，完成后可“同种子复测当前代码”。属于正式提交，会保存历史。

**正式提交历史**：查看每次代码和结果，可恢复到编辑器；替换草稿前提醒确认。修改代码后，旧结果明确提示不代表当前代码。

状态：AC 全通过；WA 答案/格式错；CE 语法错；RE 运行异常；TLE 超时；MLE 内存监控超限；OLE 输出超限；CANCELLED 取消；IE 判题内部错；INTERRUPTED 服务重启中断。内部错误不会当作用户答案错误。

## 补全、笔记和手动结果

上下文补全默认开启，提示变量、方法、导入和函数参数；Ctrl+Space 手动触发，可关闭。使用本机静态分析，不执行源码、不调用 AI；首次分析某些模块可能稍慢。

括号与单双引号自动配对；选中文字后输入左符号可包裹，已有闭合符号会跳过，空配对可整对退格删除。支持 Python 三引号、转义与 r/f 等前缀；粘贴或恢复已有代码不会重新配对。第三版其他功能的交付状态见开发计划。

代码默认 14px、字重 600，较原来更清晰；页面其他区域保留原字号。

代码区支持捏合手势及 Ctrl＋滚轮调字号，普通两指上下/左右滑动仍滚动代码。底部 A−/A＋也可调整，范围 10～28px，可“恢复默认”14px；浏览器记住字号。捏合事件已接入并完成浏览器事件测试，真实触控板体验仍待本机确认。

“笔记”保留思路、关键点、注意事项、易错边界、Python 参考代码五栏，手动保存，支持 Markdown 预览。查看笔记和历史不自动改结果。

独立完成且无错手动选 ✅，看提示或过程中出错选 ❌。最终 AC 也可以记 ❌。保存时只关联当天完全相同代码的最近有效判题，修改后未重交不关联旧 AC。

每天每题一条手动记录，可有多次提交。首页连续最近 7 天，最新在左，未做留空，“更早日期”向右加载；悬停 ❌ 看标签，点击看说明、代码和关联判题。当天可改，历史只读，无补录。

当天草稿自动恢复，新一天从空白开始。跨日未保存代码请先复制，再返回首页重新打开，不自动带入新一天。

## 限制与验证

只运行自己信任的代码。本机执行不隔离文件或网络，不用于公开多人判题。每批默认 3 秒、16 MB 输出、256 MB 采样内存监控，这些不是官方平台限制，内存监控也非严格瞬时配额。运行仅提供 Python 标准库。

测试集说明见 `judge-coverage.md`，不等同官方隐藏用例。原地操作、深拷贝等内部要求由自己检查。

```powershell
python -m unittest discover -s tests -v
python -m judge.audit
python -m judge.benchmark
```

以上验证不写个人数据库；后两条会更新 docs/ 中的覆盖和性能报告。
