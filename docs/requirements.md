# 第一版需求

确认日期：2026-10-29。本文整理自需求讨论，作为第一版开发和验收依据。

## 1. 目标与范围

提供个人刷题记录、复习选题和笔记管理能力。面向电脑端本地网页，单人、单机使用，无需登录。数据在本机持久保存，具体实现尚未选择。

核心流程：选题 → 阅读题目、编写代码 → 复制到外部平台自行验证 → 手动保存结果和错误 → 回到矩阵查看 → 整理长期笔记。

## 2. 首页记录矩阵

- 每行一道题，每列一个自然日。
- 默认连续展示最近 7 个自然日，以今天为起点，最新日期在左侧；没有练习的日期也展示。
- 更早日期向右滚动查看。当天没有做过某题，对应格子留空。
- 同一道题每天只保存一条练习记录，不设计同日多次练习、次数或首次结果逻辑。
- 有记录的格子显示 ✅ 或 ❌；悬停在 ❌ 上展示错误标签，点击记录查看完整错误说明和当次代码。
- 顶部提供按类型练习和随机复习入口，支持题目筛选。
- 不提供通过率、周期或轮次统计。

## 3. 题库与选题

- 第一版预置力扣 Hot 100，并按类型组织。
- 支持手动添加其他题目，至少包含题号、标题、力扣链接、类型和题目内容。
- 支持批量标记“以前做过”，使这些题加入随机复习范围，但不生成历史日期记录或 ✅／❌。
- 保存过练习记录的题也进入已做题范围。
- 按类型练习：展示对应题目列表，由用户选题，练习页支持“下一题”。
- 随机复习：默认从已做题中完全随机抽取，支持限定类型或题单，符合条件的题等概率抽取。
- 不实现错题权重、久未复习权重或智能推荐；不承诺跨次抽题去重或轮次管理。
- 允许“换一题”，跳过不生成练习结果，保留已有草稿。
- 随机练习开始时隐藏类型、长期笔记和历史结果，避免提示；用户可主动查看相关内容。

## 4. 练习页面与代码编辑

- 展示力扣原题链接、题目描述、示例输入输出及约束条件。
- 不额外编写或转换 ACM 输入输出格式说明。
- 提供 Python 编辑器，用户可自行编写 ACM 格式完整程序。
- 支持语法高亮、自动缩进、草稿自动保存、一键复制；默认关闭代码补全。
- 新一天的练习从空白代码开始，不自动加载历史解法；当天未完成的草稿自动恢复。
- 历史代码可主动查看。代码草稿与正式练习结果区分保存，只有手动保存结果才在矩阵中形成记录。
- 不运行代码、不自动验证、不判题，不接入 AI 判题。
- 用户复制代码到外部平台自行验证；代码是否匹配外部平台输入输出要求由用户处理。

## 5. 练习结果与错误

- 独立完成且没有出错记 ✅。
- 看过提示或代码出现错误，即使之后修正并通过，也记 ❌。
- 最终由用户手动选择结果；打开笔记、查看历史代码或参考代码不会自动更改结果。
- 每条记录关联题目、当天日期、结果和当次代码；❌ 另关联错误标签及选填说明。
- 错误标签可多选，支持自定义标签。
- 预置标签：思路没想出、看了提示、算法逻辑错误、边界遗漏、代码实现错误、复杂度不达标、输入输出错误。
- 只记录当天，不提供历史补录；当天已有记录可修改，不新增第二条。

## 6. 长期笔记

每题有五个固定栏目，与每日练习记录独立保存：

1. 解题思路。
2. 关键点。
3. 注意事项。
4. 易错边界。
5. Python 参考代码（选填）。

文字栏目支持 Markdown 和代码块。练习时默认隐藏笔记，用户主动展开后查看或编辑。每日错误说明不自动覆盖长期笔记，整理过程由用户控制。

## 7. 第一版不做

- 用户账号、登录和跨设备同步。
- 手机端专门适配、桌面应用打包。
- 代码执行、测试用例运行、自动判题、AI 判题。
- 通过率、周期统计、复习轮次管理。
- 同题同日多次练习记录、历史补录。
- 数据导入导出备份、力扣账号做题历史同步。
- 智能复习调度、错题加权随机、自动提示或自动标记结果。

## 8. 验收场景

1. 打开首页可见连续 7 个自然日；无练习处留空，可向右查看更早日期。
2. 批量标记以前做过的题后，可随机抽到这些题，但矩阵不生成过去记录。
3. 按类型选题后查看原题并编写 Python 代码，刷新页面可恢复当天草稿，一键复制保留代码格式。
4. 保存 ✅ 后出现当天记录；保存 ❌ 时可关联多个错误标签和文字说明。
5. 悬停 ❌ 可看标签，点击可看说明和当次代码；修改当天记录后仍只有一个格子结果。
6. 换题不生成结果，再次打开可恢复当天草稿；新一天不自动加载旧代码。
7. 五栏长期笔记可保存和再次查看；查看笔记不自动改变练习结果。
8. 关闭并重新启动工具后，题库标记、笔记、练习结果和应保留的草稿仍存在。

## 9. 实现决策追踪

- 前后端技术栈、数据库或其他本机持久化方式、启动方式。
- Hot 100 具体版本、题目内容获取与维护方式、题型分类映射。
- 题目内容缺失时的补充流程。
- 更早日期的加载范围、页面具体布局。
