# LeetCode Review

面向个人的本地刷题复习记录工具，主要解决“刷过就忘”和复习记录分散的问题。第一版面向电脑浏览器，单机使用，无需登录，数据保存在本机。

## 第一版体验

- 首页以“题目 × 日期”矩阵展示练习记录。
- 预置力扣 Hot 100，支持手动添加题目、按类型练习和完全随机复习。
- 练习页展示力扣链接、原题描述、示例及约束，提供 Python 代码编辑区。
- 手动记录每天的 ✅／❌、当次代码、错误标签和错误说明。
- 每道题维护长期笔记及 Python 参考代码。

完整范围见 [需求文档](docs/requirements.md)，设计取舍见 [决策记录](docs/decisions.md)，开发过程见 [开发日志](docs/dev-log.md)。

## 本地启动

待项目实现后补充安装依赖、启动命令和数据存储路径。

## 版本管理

每完成一个有意义的功能或修复，创建一次 Git 提交，并更新必要的文档和验证结果。代码、需求、设计决定和开发日志进入版本管理；个人运行数据、密钥、虚拟环境和生成文件不提交。
## Git 开发流程

远程仓库：https://github.com/Mist-oo/LeetCode-review 。第一版在 `main` 分支按功能提交。

- 每完成一个可验证的功能或独立修复，检查差异并运行与改动相称的验证。
- 在同一次提交中包含代码、相关文档和开发日志；日志记录实际完成内容、关键决定、验证结果和遗留问题。
- 使用 `feat:`、`fix:`、`docs:`、`chore:` 描述提交用途；同次日志不填写自身提交哈希，通过 Git 历史关联。
- 每次提交后推送 GitHub；推送失败保留本地提交，恢复连接后补推，不强制推送或覆盖远程历史。
- 不提交 IDE 配置、虚拟环境、个人运行数据库、密钥或生成文件；不建立后台自动提交任务。
